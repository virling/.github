Virling joins every visit to the payment that followed, so founders can see which channels bring paying customers.

- One Rust binary with embedded storage. No Postgres, no ClickHouse, no Redis.
- Connects to Stripe, Dodo Payments, Polar and LemonSqueezy with a read-only key.
- Tracking script under 5 KB. Visitor IPs are never stored.
- AGPL-3.0, free to self-host. A hosted version is coming.
